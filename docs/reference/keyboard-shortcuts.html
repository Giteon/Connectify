Keyboard Shortcuts

A cheatsheet for every shortcut in the editor. On macOS use Cmd; on Windows / Linux use Ctrl.

Selection

ShortcutAction
ClickSelect a node
Shift + ClickAdd / remove from selection
Drag (empty canvas)Marquee select
Cmd / Ctrl + ASelect all nodes
EscapeDeselect everything

History & clipboard

ShortcutAction
Cmd / Ctrl + ZUndo
Cmd / Ctrl + Shift + ZRedo
Cmd / Ctrl + CCopy selected nodes
Cmd / Ctrl + VPaste at cursor
Cmd / Ctrl + XCut
Delete / BackspaceRemove selected nodes
Cmd / Ctrl + DDuplicate selection in place

Tools

ShortcutAction
VSelect tool
PPath tool
MMarquee tool
NAdd node menu

Canvas navigation

ShortcutAction
Space + DragPan canvas
ScrollPan vertically
Shift + ScrollPan horizontally
Cmd / Ctrl + ScrollZoom in / out
Cmd / Ctrl + 0Reset zoom to 100%
Cmd / Ctrl + 1Fit graph to view

Inspector & panels

ShortcutAction
IToggle Inspector
Escape (in Inspector)Close Inspector
C (with node selected)Open Comments tab
Cmd / Ctrl + KCommand palette

Subgraphs

ShortcutAction
Cmd / Ctrl + GGroup selection into subgraph
Cmd / Ctrl + Shift + GUngroup subgraph
Double-click subgraphEnter / expand

Run

ShortcutAction
Cmd / Ctrl + EnterRun current variant
Cmd / Ctrl + .Cancel running
